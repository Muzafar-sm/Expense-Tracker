# Expense Tracker

 ## Live site
[Live Site](https://expense-tracker-kohl-one-59.vercel.app/)
A modern expense tracking application built with React and Material-UI, featuring a clean interface and powerful functionality for managing personal finances.

## Features

- 📊 Interactive dashboard with charts and statistics
- 💰 Easy expense management (add, edit, delete)
- 📱 Responsive design for all devices
- 🌓 Light/Dark mode support
- 📈 Detailed reports and analytics
- 🔍 Search and filter expenses
- 📅 Date-wise expense tracking

## Tech Stack

- **Frontend Framework**: React 19
- **Build Tool**: Vite 6.3
- **UI Library**: Material-UI (MUI) 7.0
- **Routing**: React Router DOM 7.5
- **Charts**: Recharts 2.15
- **Date Handling**: Date-fns 4.1
- **Icons**: Material Icons, React Icons
- **Styling**: Emotion (MUI Styling Solution)

## Getting Started

### Prerequisites

- Node.js (version 16 or higher)
- npm or yarn

### Installation

1. Clone the repository
```bash
git clone <your-repo-url>
cd expense-tracker
```
